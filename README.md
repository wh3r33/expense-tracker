#Personal Expense Tracker

Современное и приватное веб-приложение для контроля личных финансов прямо в вашем браузере. Весь учет ведется локально: данные не отправляются на сервер, обеспечивая полную конфиденциальность.

---

## ✨ Особенности проекта

*   **Полная приватность**: Работает на `localStorage` — ваши данные остаются только на вашем устройстве.
*   **Мультивалютность**: Поддержка **KZT**, **USD**, **EUR** и **RUB** с возможностью выбора базовой валюты для сводных отчетов[cite: 1, 3].
*   **Визуализация данных**: Интерактивная круговая диаграмма (Chart.js), отображающая структуру ваших расходов по категориям[cite: 2, 3].
*   **Система лимитов**: Устанавливайте бюджет на каждую категорию и получайте предупреждения при его превышении[cite: 2].
*   **Персонализация в стиле Notion**: Настраивайте иконки-emoji для каждой категории прямо в интерфейсе[cite: 1, 3].
*   **Кастомный дизайн**: Поддержка светлой («Soft») и темной («Night») тем, а также возможность загрузить собственное фоновое изображение для шапки[cite: 1, 2].
*   **Экспорт данных**: Возможность скачать историю операций в формате **CSV** для дальнейшего анализа в Excel или таблицах[cite: 1, 2].
*   **Двуязычный интерфейс**: Полная поддержка русского и английского языков[cite: 3].

## Как это работает

Приложение построено на базе чистого стека технологий без необходимости сборки или бэкенда:

1.  **HTML5 & CSS3**: Семантическая верстка и адаптивный дизайн с использованием CSS Variables для тем оформления[cite: 4].
2.  **Vanilla JavaScript**: Вся логика — от расчетов конвертации до управления состоянием — написана на чистом JS[cite: 2, 3].
3.  **Chart.js**: Библиотека для отрисовки динамической графики[cite: 1, 3].
4.  **Local Storage**: Используется для хранения ваших расходов, настроек тем, выбранных лимитов и даже пользовательского фона[cite: 2, 3].

### Установка и запуск
1. Клонируйте репозиторий.
2. Откройте файл `index.html` в любом современном браузере.
3. Готово! Приложение готово к работе.

## 🛠 Технические детали

*   **Конвертация**: Используются фиксированные курсы валют (относительно KZT) для обеспечения стабильной работы без внешних API[cite: 2, 3].
*   **Безопасность**: Приложение не требует регистрации и не собирает файлы cookie.
*   **Адаптивность**: Интерфейс полностью оптимизирован для работы на мобильных устройствах и десктопах (macOS/Windows)[cite: 2, 4].
