#Personal Expense Tracker

Современное и приватное веб-приложение для контроля личных финансов прямо в вашем браузере. Весь учет ведется локально: данные не отправляются на сервер, обеспечивая полную конфиденциальность.

---

## ✨ Особенности проекта

*   **Полная приватность**: Работает на `localStorage` — ваши данные остаются только на вашем устройстве.
*   **Мультивалютность**: Поддержка **KZT**, **USD**, **EUR** и **RUB** с возможностью выбора базовой валюты для сводных отчетов
*   **Визуализация данных**: Интерактивная круговая диаграмма (Chart.js), отображающая структуру ваших расходов по категориям
*   **Система лимитов**: Устанавливайте бюджет на каждую категорию и получайте предупреждения при его превышении
*   **Персонализация в стиле Notion**: Настраивайте иконки-emoji для каждой категории прямо в интерфейсе
*   **Кастомный дизайн**: Поддержка светлой («Soft») и темной («Night») тем, а также возможность загрузить собственное фоновое изображение для шапки
*   **Экспорт данных**: Возможность скачать историю операций в формате **CSV** для дальнейшего анализа в Excel или таблицах
*   **Двуязычный интерфейс**: Полная поддержка русского и английского языков

## Как это работает

Приложение построено на базе чистого стека технологий без необходимости сборки или бэкенда:

1.  **HTML5 & CSS3**: Семантическая верстка и адаптивный дизайн с использованием CSS Variables для тем оформления
2.  **Vanilla JavaScript**: Вся логика — от расчетов конвертации до управления состоянием — написана на чистом JS3
3.  **Chart.js**: Библиотека для отрисовки динамической графики
4.  **Local Storage**: Используется для хранения ваших расходов, настроек тем, выбранных лимитов и даже пользовательского фона

### Установка и запуск
1. Клонируйте репозиторий.
2. Откройте файл `index.html` в любом современном браузере.
3. Готово! Приложение готово к работе.

## 🛠 Технические детали

*   **Конвертация**: Используются фиксированные курсы валют (относительно KZT) для обеспечения стабильной работы без внешних API
*   **Безопасность**: Приложение не требует регистрации и не собирает файлы cookie.
*   **Адаптивность**: Интерфейс полностью оптимизирован для работы на мобильных устройствах и десктопах
